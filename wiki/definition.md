# 什麼是 AI Agent？

> 摘要：Agent 是能感知環境並採取行動以達成目標的系統；LLM Agent 則是由大型語言模型「自己決定流程與工具使用」的系統。

## 重點
- 經典定義：Agent 是任何能透過感測器感知環境、並透過致動器對環境採取行動的東西。[S14]
- LLM Agent：由 LLM 動態主導自己的流程與工具使用，自己決定如何完成任務。[S1]
- 與 Workflow 的差別：Workflow 是由程式碼預先寫好路徑來串接 LLM 與工具；Agent 則是由模型在執行中決定下一步。[S1]
- 與聊天機器人的差別：聊天機器人多半一問一答；Agent 會連續多步行動、使用工具並根據環境回饋修正。[S1][S2]
- Agent 會帶來更高的延遲與成本，只有在任務開放、步驟無法事先預測時才值得使用。[S1]

## 說明
### 自主程度是一條光譜
從「單次 LLM 呼叫」→「加上檢索與工具的強化 LLM」→「預先寫好的 Workflow」→「自主 Agent」，每往右一步，彈性變高，但可預測性與成本控制變差。[S1] 詳見 [[workflows-vs-agents]]。

### 一個生活化的例子
請 Agent「幫我訂下週五台北到台中的高鐵，越早越好」：它要查時刻表（工具）、比對你的行事曆（記憶／工具）、遇到滿座就改查下一班（觀察 → 修正），最後回報結果。這種「做了才知道下一步」的任務，就是 Agent 的強項。（此例為本 Wiki 自編教學例，非引自來源）
