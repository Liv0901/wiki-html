# 風險與防護

> 摘要：Agent 能自主行動，所以錯誤的代價也更高。主要風險包含提示注入、過度授權、錯誤累積與成本失控。

## 重點
- 提示注入（Prompt Injection）名列 OWASP LLM 應用十大風險第一名（LLM01），惡意指令可能藏在 Agent 讀到的網頁或文件中。[S13]
- 過度授權（Excessive Agency，LLM06）：給 Agent 過多功能、權限或自主性，可能導致有害的行動。[S13]
- 無上限消耗（Unbounded Consumption，LLM10）：缺乏限制時，迴圈或大量請求可能造成成本與資源失控。[S13]
- Agent 的自主性意味著更高成本與錯誤累積的可能，需在沙盒中測試並設置防護。[S1]
- 對重要步驟設置人類檢查點，讓 Agent 在關鍵時刻暫停並取得人類回饋。[S1]
- 間接提示注入：攻擊者把指令藏進 Agent 可能檢索到的資料（如網頁），不需直接接觸系統就能操控它；研究已在 Bing 的 GPT-4 聊天與程式補全系統上示範。[S17]

## 防護清單（整理自 [S1][S13]）
1. **最小權限**：只給完成任務必需的工具與權限（見 [[tool-use]]）。
2. **人類在迴路中**：付款、刪除、對外發信等不可逆動作需人類確認。
3. **停止條件**：最大步數、預算上限、逾時（見 [[agent-loop]]）。
4. **把外部內容當資料，不當指令**：網頁、Email、檔案中的文字不可直接當命令執行。
5. **沙盒與記錄**：在隔離環境執行，保留完整行動紀錄以便稽核（見 [[evaluation]]）。
