# 記憶

> 摘要：LLM 本身沒有跨對話的記憶，上下文長度也有限；記憶機制讓 Agent 能累積經驗、處理長任務。

## 重點
- 短期記憶＝上下文中的內容（in-context learning）；長期記憶＝存在外部（常用向量資料庫），以快速檢索取用。[S3]
- Generative Agents 用「記憶流」記錄所有經驗，依「新近度、重要性、相關性」檢索，並把記憶綜合成更高層的「反思」。[S5]
- MemGPT 借鏡作業系統的分層記憶，在有限的主上下文與外部儲存之間搬移資料，讓 LLM 處理超出上下文長度的內容。[S7]
- Reflexion 把文字反思存進「情節記憶」緩衝區，用於下一次嘗試。[S4]

## 說明
| 記憶類型 | 人類類比 | Agent 實作 |
|---|---|---|
| 感官記憶 | 一瞬間的印象 | 輸入的原始內容 |
| 短期／工作記憶 | 正在想的事 | 上下文視窗（對話、工具結果） |
| 長期記憶 | 筆記本、經驗 | 向量資料庫、檔案、摘要 |

（類比表整理自 [S3]）

### 記憶的取捨
記太少會重複犯錯；記太多會塞爆上下文、成本上升，還可能把不可信的內容永久保存（見 [[risks]]）。
