# 核心元件

> 摘要：一個 LLM Agent 通常由「LLM 大腦」加上三大能力組成：規劃、記憶、工具使用。

## 重點
- Weng 的框架：Agent ＝ LLM（大腦）＋ 規劃 ＋ 記憶 ＋ 工具使用。[S3]
- 規劃：把大任務拆成小目標，並對過去的行動做反思與修正。[S3]
- 記憶：短期記憶是上下文（in-context）中的內容；長期記憶通常存在外部向量資料庫，需要時再檢索。[S3]
- 工具使用：呼叫外部 API 取得模型權重裡沒有的資訊，例如即時資料、程式執行、專有資料庫。[S3]
- Anthropic 稱基本積木為「強化型 LLM」（augmented LLM）：LLM 加上檢索、工具與記憶。[S1]
- Wang 等人的綜述整理大量既有研究，提出一個涵蓋多數 LLM 自主代理人研究的統一框架，並整理其在社會科學、自然科學與工程上的應用與評估策略。[S15]
