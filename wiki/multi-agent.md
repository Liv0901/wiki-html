# 多代理人系統

> 摘要：讓多個各有角色的 Agent 分工、對話、互相檢查，來完成單一 Agent 難以處理的任務。

## 重點
- AutoGen 讓多個可對話的 Agent 透過互相傳訊合作完成任務，Agent 可結合 LLM、人類輸入與工具。[S10]
- Generative Agents 在沙盒小鎮中放入 25 個 Agent，它們會自發地互相傳遞消息、結交朋友並協調活動（例如籌辦情人節派對）。[S5]
- 協調者－工作者模式中，中央 LLM 動態拆解任務並分派給多個工作者，是常見的多代理人架構。[S1]
- MetaGPT 把人類團隊的標準作業程序（SOP）寫進提示序列，用「生產線」方式分派不同角色給各個 Agent，比先前只靠聊天的多代理人系統產出更一致的結果。[S19]

## 說明
### 常見組織方式
| 架構 | 說明 | 例子 |
|---|---|---|
| 協調者－工作者 | 一個主管 Agent 分派、彙整 | 研究助理派出多個搜尋 Agent |
| 角色分工對話 | 每個 Agent 有固定角色互相對話 | 「寫程式」與「審程式」兩個 Agent |
| 辯論／投票 | 多個 Agent 各自作答後比較 | 對同一題取多數決（對應 [[workflows-vs-agents]] 的投票） |

### 好處與代價
- 好處：專業分工、互相檢查、可平行處理。
- 代價：溝通成本、token 花費倍增、錯誤可能在 Agent 之間傳染，除錯更困難（見 [[risks]]、[[evaluation]]）。
